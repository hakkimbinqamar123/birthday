# Ayshu's Birthday Treasure Hunt (React + Vite)

## Run it
    npm install
    npm run dev        # open the local URL it prints
    npm run build      # production files go to /dist (upload them to any static host)

## Personalise it
Edit `src/data.js`: name, treasure messages and positions, romantic questions,
love coupons and the final letter. Colours and styles live in `src/styles.css`.
